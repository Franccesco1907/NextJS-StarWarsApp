# Star Wars registry

Next.js 13/React app listing SWAPI characters with species, homeworld and vehicle details.

- Run `npm ci`, then `npm run dev`; open `http://localhost:3000`.
- Requests are defined in `app/functions/requests.ts` and require access to `https://swapi.dev/api/`.
- Checks: `npm run lint`, `npm test`. Production: `npm run build`, then `npm start`.
